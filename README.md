# Keys

A standalone, landscape-first piano-by-ear web app built for one learner (Steve), designed for iPhone and hosted on GitHub Pages (`https://autodax.github.io/keys/`).

This repo is currently in the design and planning stage. Read `AGENTS.md` for working rules and `notes/keys.md` for every decision, brainstormed idea, and open question.

## The goal

Play around on a piano keyboard and internalize the sounds of all the keys so that you can **pick out melodies very quickly—and ultimately chords—by ear**, starting from very little prior knowledge and keeping it genuinely fun.

## Core principles

- **Landscape iPhone, almost all keyboard:** A two-octave warm ivory piano fills the screen, with minimal information in the slim strip above it.
- **Playful, not a drill:** Start with one note repeated rhythmically (call-and-response and playing along with a backing chord), then two notes with the first key illuminated so you always have a visual and musical anchor.
- **Hunt by ear early, tighten up later:** In early stages, tapping any key plays its real piano sound so you can hunt by ear until you land on the right note. Later on, it transitions smoothly to one-shot guesses.
- **No discrete levels (long-term):** Instead of moving through numbered levels, the app tracks successes and mistakes and gradually, seamlessly expands the challenge—sprinkling in review to build confidence, with an optional quick warm-up/recap that ramps up to your current spot.
- **Full keyboard always visible:** All two octaves stay on screen from day one, with active keys gently spotlighted so you build real spatial memory without feeling overwhelmed.
- **Clean keys:** No letters or numbers during challenges; note names appear only in Free Play.
